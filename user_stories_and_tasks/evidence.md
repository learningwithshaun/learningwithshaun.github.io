## Epic A — Zuke Documentation Site

### US-01 · Onboarding & tooling
**As a** developer intern, **I want** to understand the company, my role and WordPress, **so that** I can contribute to the Zuke documentation site.
**AC:** I can build and edit pages in WordPress independently; the design direction (colours, look and feel) is agreed.
- T1.1 Attend company onboarding
- T1.2 Work through the WordPress guide
- T1.3 Brainstorm the site's look (colours, layout, design)

### US-02 · Documentation landing page
**As a** Zuke user, **I want** a clear landing page for the documentation, **so that** I can quickly find help.
**AC:** Page built in WordPress + Elementor; layout approved by the mentor; works on desktop and mobile.
- T2.1 Sketch layout options
- T2.2 Build the page in Elementor
- T2.3 Iterate on layouts and designs
- T2.4 Get the final version approved

### US-03 · Journey 1 — Sign-up guide
**As a** new Zuke customer, **I want** step-by-step instructions for signing up on zuke.co.za, **so that** I can create an account without support.
**AC:** Every step of the sign-up flow is covered in the correct order, with clear instructions; reviewed by the mentor.
- T3.1 Walk through the sign-up process and note each step
- T3.2 Write step-by-step instructions
- T3.3 Add screenshots/visuals
- T3.4 Build the Journey 1 page and review it

### US-04 · Additional user journeys
**As a** Zuke user, **I want** guides for the other key tasks on Zuke, **so that** I can use the product fully.
**AC:** Each journey follows the Journey 1 format; reviewed and approved.
- T4.1 Agree the list of journeys with the mentor
- T4.2 Document and build each journey
- T4.3 Review and revise based on feedback

### US-05 · Review, QA & publish
**As a** Zuke user, **I want** an accurate, polished site, **so that** I can trust the documentation.
**AC:** All links work; content proofread; responsive on mobile; mentor sign-off.
- T5.1 Proofread all pages
- T5.2 Test links and mobile layout
- T5.3 Fix issues and publish

## Epic B — Lulem Digital Signage

### US-06 · Ad playback
**As a** retail business owner, **I want** my images and videos to play on the in-store TV, **so that** I can promote my products.
**AC:** Images and videos play in sequence without errors on the TV.
- T6.1 Set up media playback
- T6.2 Test with sample ads
- T6.3 Fix issues

### US-07 · Paystack QR payments
**As a** customer in a store, **I want** to scan a Paystack QR code on the TV, **so that** I can pay quickly.
**AC:** The QR code displays clearly; scanning opens the correct Paystack payment page.
- T7.1 Integrate the Paystack QR code
- T7.2 Test scan and payment flow

### US-08 · YouTube between ad sessions
**As a** store owner, **I want** YouTube videos to play between ad sessions, **so that** the screen keeps customers engaged.
**AC:** YouTube content plays between ads and returns to ads without manual action.
- T8.1 Add the YouTube player
- T8.2 Schedule playback between ad sessions
- T8.3 Test transitions

### US-09 · Raspberry Pi setup
**As a** developer, **I want** to understand and configure the Raspberry Pi, **so that** Lulem runs reliably on retail TVs.
**AC:** The Pi boots into Lulem and runs it on the TV.
- T9.1 Learn the Pi's role in running Lulem
- T9.2 Configure the Pi for Lulem
- T9.3 Test on a TV

### US-10 · Pi cooling case
**As a** developer, **I want** a fan case for the Raspberry Pi, **so that** it doesn't overheat during long runs.
**AC:** Case fits the Pi and fan; Pi runs cooler.
- T10.1 Design the fan case
- T10.2 3D-print the case
- T10.3 Fit and test the case
